EReasoning
The Matrix direction trades the cold amber/graphite split for a phosphor-green code rain. Katakana glyphs (ﾊ ﾐ ﾋ ｳ ｼ ﾈ ﾂ ｦ…) fall down the left and right columns with a white-hot head and dim green tail — the Wachowskis' canonical treatment.

The center glyph is doing double duty: read it as a terminal prompt (> █ — chevron, phosphor block cursor, trailing katakana ｦ) or as a stylized φ for phosphor. Corner brackets and the /03 stamp survive the palette swap so the icon stays in the same family as the in-app chrome.

A magenta • in the top-left of the glyph is a live status LED — it pulses hot when an agent needs input. On a launcher, the green rain reads cyberpunk at any size; at a glance in a tray of 24 icons, the phosphor head is the only pure-white pixel around.

No robot face. No neural-net mesh. No gradient orb. Just the terminal, falling.
