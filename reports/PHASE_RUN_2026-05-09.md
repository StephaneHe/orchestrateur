**Methodology gap** : the microbench measures call-site latency in a tight
loop where libuv's worker-pool dispatch overhead dominates for small reads.
The patches' real benefit is event-loop unblocking under *concurrent* load
(the dispatch handler can serve other requests while a 256 KB tail read
runs). Demonstrating that requires a live concurrent-load test against a
running server with the new code. See § 7.
