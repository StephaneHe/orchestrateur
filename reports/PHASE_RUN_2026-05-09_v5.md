### 2.2 Server.js diff (high-level)

```diff
+ import { detectOverride } from './src/message_router.mjs';

  // … inside POST /api/dispatch, right after request_in trace …
+ const overrideDetected = detectOverride(prompt);
+ const forceFlag = req.body?.force_interrupt === true;
+ const isOverride = overrideDetected.override || forceFlag;
+ const promptForRouting = overrideDetected.override
+   ? overrideDetected.stripped
+   : prompt;
+ if (isOverride) {
+   // append explicit_override line to logs/router-<isoDate>.ndjson
+   // with override_source = 'prefix' | 'api_flag'
+   // … traceWrite + debugLog …
+ }

  // legacy cooperative-interrupt block now branches on isOverride :
- let effectivePrompt = prompt;
+ let effectivePrompt = isOverride ? promptForRouting : prompt;
  …
- const captured = await captureInterruptStateAsync(name);
+ const captured = isOverride ? null : await captureInterruptStateAsync(name);
  …
- effectivePrompt = formatInterruptResumeNotice(captured, prompt);
+ if (!isOverride) effectivePrompt = formatInterruptResumeNotice(captured, prompt);
```

The legacy `captureInterruptStateAsync` + `formatInterruptResumeNotice`
path is preserved for non-override interrupts ; that's what the old
ad-hoc cooperative-interrupt logic was doing, and it remains the
fallback for any in-flight dispatch that didn't carry `!interrupt`.

### 2.3 Why classifier is NOT in the dispatch hot path

`POST /api/dispatch` currently responds to the client in O(ms). Calling
`classify(...)` (Haiku via `claude --print`) adds 5–30 s. Wiring it
into the synchronous handler would regress UI responsiveness for every
mid-flight dispatch where the classifier would actually be needed
(i.e., when no stop-word and no override match — the most ambiguous
case).

Recommended next step (post-v5) : feature-flag the classifier path as
a server config option, default off. Or move classifier to a side
queue : POST returns 202 immediately, classifier runs async, decision
applied when verdict arrives. That's a half-day of focused work.

Request :
```http
POST /api/dispatch?token=… HTTP/1.1

{"project":"vuBox","prompt":"!interrupt say only the word ack"}
```

Response (in 8 ms) :
```json
{"ok":true,"project":"vuBox","pid":277548,"interrupted":false,
 "trace_id":"e40762b5"}
```

Router NDJSON entry written synchronously :
```json
{"ts":"2026-05-09T10:45:05.536Z","decision":"interrupt",
 "reason":"explicit_override","source":"production","agent_id":"vuBox",
 "prompt_excerpt":"say only the word ack","in_flight_turn_age_ms":null,
 "queue_depth_after":0,"override_source":"prefix",
 "trace_id":"e40762b5"}
```

Real claude received the **stripped** prompt `"say only the word ack"`
and emitted the expected result event :
```json
{"type":"result","subtype":"success","is_error":false,
 "duration_ms":3859,"num_turns":1,"result":"ack",
 "stop_reason":"end_turn",
 "session_id":"2fedaacc-c69d-4dfc-8bad-6771795080ea",
 "total_cost_usd":0.14585025,
 "usage":{"input_tokens":3,…}}
```

This validates :
- override detection (prefix recognised)
- prompt stripping (`!interrupt say only the word ack` → `say only the word ack`)
- telemetry write (`logs/router-2026-05-09.ndjson` line +1)
- production flow regression-free (real claude completed, exit 0)
